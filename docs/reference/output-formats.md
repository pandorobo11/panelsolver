# Output format reference

The complete result contracts are now split by artifact:

- [Summary CSV reference](../results/summary-csv.md): encoding, column order,
  row scopes, types, units, blank conditions, and every result column;
- [VTP reference](../results/vtp.md): PolyData mesh, cell arrays, field data,
  shapes, stored types, units, and integration roles.

This page is retained so existing documentation links continue to resolve. It is
not a second schema definition. Per-case artifact paths are defined with
[Case files](../user-guide/case-files.md), generic checkpoints and recovery in
[Batch execution and recovery](../user-guide/batch-execution-and-recovery.md),
and image export in the [GUI guide](../user-guide/gui.md). Frames, signs,
normalization, and common equations are defined in
[Coordinate and attitude conventions](coordinate-and-attitude-conventions.md),
[Load and coefficient conventions](load-and-coefficient-conventions.md), and
the solver pages.
