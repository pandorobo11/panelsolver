# Local legacy references

This directory is reserved for local, read-only checkouts of `fmfsolver` and
`newtsolver`. The checkouts are intentionally ignored by Git. Their authoritative
repositories and pinned commits are recorded in
[`devdocs/history/migration/MIGRATION_SOURCES.md`](../devdocs/history/migration/MIGRATION_SOURCES.md).

Do not edit legacy source through this directory. In the current workspace, the
sibling repositories `../fmfsolver` and `../newtsolver` may be used instead when
they match the recorded commits.
